### Verification scope

1. Python syntax and command-line help for all three scripts.
2. AST comparison: after masking human-readable string literals and the two default working-directory declarations, **all three source files have the same Python expression and control-flow structure as their respective originals**.
3. Stage 12A: small Optuna/grouped-CV/held-out-prediction smoke run on all 1,001 cleaned records, under the reduced smoke-test scope.
4. Stage 12B: small input-to-output smoke run with artificial historical Optuna trials (not manuscript data/results).
5. Stage 13-0: held-out-fold prediction smoke run using artificial frozen model configurations (not manuscript results).
6. The English workbook sheet names generated by Stage 12B are the names checked by Stage 13-0.

These checks do not replace a full historical rerun or audit of the original field measurements and data cleaning.

### Additional interface cross-check

- 12A/12B historical Optuna study identifier construction matches (`12A__Season__foldN__YYYYMMDD__EP__Model`).
- Stage 12B and Stage 13-0 contain the same ordered five-family list and the same base seed. The eight XGB outer-fold fit seeds were checked for exact equality.
- Stage 13-0 successfully read an eight-fold **synthetic** Stage 12B-format workbook using the translated sheet names. This is an interface test, not a full manuscript replication.
- A stale, noncomputational output filename associating held-out-fold performance with manuscript Table S2 was corrected.
